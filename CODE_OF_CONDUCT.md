# Code of Conduct

## Our Standards

We want this project to be a respectful, technically rigorous collaboration space.

Examples of expected behavior:
- constructive and specific feedback;
- respectful communication;
- evidence-based technical discussion;
- openness to correction and iteration.

Examples of unacceptable behavior:
- harassment, insults, or discrimination;
- personal attacks or hostile tone;
- intentionally misleading technical claims;
- sharing private data or secrets.

## Enforcement

Project maintainers may remove, edit, or reject contributions and interactions
that violate this Code of Conduct.

## Reporting

If you experience or witness unacceptable behavior, contact project maintainers
via private channel (GitHub profile contact).
