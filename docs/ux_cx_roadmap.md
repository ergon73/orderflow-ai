# UX/UI & CX Roadmap (post-MVP)

Цель: улучшить пользовательский опыт в Telegram-боте и на storefront,
связав UX-изменения с измеримыми бизнес-метриками.

---

## 1) Discovery и базовые метрики

- [ ] `UX-01` Провести UX-аудит ключевых сценариев (бот + storefront) и зафиксировать top pain points.
- [ ] `UX-02` Зафиксировать baseline-метрики:
`conversion_to_order`, `drop_off_rate`, `time_to_confirm`, `needs_info_rate`.
- [ ] `UX-03` Сформировать CJM и список критичных UX-гипотез по этапам воронки.

## 2) Улучшения UX бота

- [ ] `UX-BOT-01` Улучшить conversational flow:
более понятные сообщения, последовательные шаги, явные ожидания по данным.
- [ ] `UX-BOT-02` Добавить quick replies/inline actions для типовых ответов и исправлений.
- [ ] `UX-BOT-03` Улучшить UX ошибок и fallback:
понятный текст, что делать дальше, без "молчаливых" сценариев.
- [ ] `UX-BOT-04` Добавить статусные уведомления по ходу выполнения заказа (прозрачность процесса).

## 3) Улучшения UX storefront

- [ ] `UX-WEB-01` Упростить форму заказа и уменьшить когнитивную нагрузку (минимум обязательных полей).
- [ ] `UX-WEB-02` Усилить валидацию и микрокопирайтинг:
контекстные подсказки, понятные тексты ошибок, прозрачные CTA.
- [ ] `UX-WEB-03` Оптимизировать мобильный UX и первый экран (`above the fold`).
- [ ] `UX-WEB-04` Улучшить экран подтверждения заказа и ожидания следующих шагов.

## 4) Quality, Accessibility, Experiments

- [ ] `UX-QA-01` Ввести accessibility baseline:
контраст, видимый фокус, keyboard navigation, читаемые ошибки.
- [ ] `UX-QA-02` Провести usability-smoke тест на реальных сценариях A/B/C/D.
- [ ] `UX-QA-03` Провести A/B тесты 2-3 ключевых гипотез (бот + storefront).

## 5) KPI и критерий приемки

- [ ] `UX-KPI-01` Достичь целевых KPI (зафиксировать числа после baseline):
рост `conversion_to_order`, снижение `drop_off_rate`, снижение `needs_info_rate`,
сокращение `time_to_confirm`.
- [ ] `UX-GATE-01` UX/CX трек принят после подтверждённого улучшения KPI и прохождения usability-smoke.

---

## Почему это важно для бизнеса

Для данного продукта UX напрямую влияет на выручку и операционную нагрузку:
- выше конверсия intake -> больше подтверждённых заказов;
- меньше `needs_info` -> меньше ручной доработки менеджерами;
- более быстрый и понятный flow -> ниже потери клиентов на шагах оформления.
