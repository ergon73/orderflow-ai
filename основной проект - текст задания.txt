Проект: AI-система обработки заказов для e-commerce
🧠 Описание проекта
AI-система для автоматической обработки заказов в e-commerce. Принимает заказы из разных каналов, понимает запросы на естественном языке, автоматически создаёт заказы в CRM и управляет процессом от заявки до оплаты.

🎯 Цель
Научиться создавать омниканальные системы, работать с NLU для бизнес-процессов и интегрировать CRM и платёжные системы.

📌 Этапы выполнения
Этап 1: Проектирование

Спроектировать data flow системы
Создать структуру базы данных
Разработать API endpoints
Этап 2: Приём заказов

Создать Telegram-бота
Реализовать парсинг email
Добавить веб-форму
Настроить единую очередь обработки
Этап 3: AI-парсинг заказов

Создать промпты для извлечения информации
Реализовать валидацию данных
Добавить уточняющие вопросы клиенту
Этап 4: CRM-интеграция

Интегрировать с Google Sheets или Airtable
Реализовать автоматическое создание записей
Настроить синхронизацию данных
Этап 5: Доставка и оплата

Интегрировать API службы доставки
Добавить расчёт стоимости
Реализовать платёжную систему
Создать генерацию счетов
Этап 6: Dashboard для менеджера

Создать интерфейс управления заказами
Добавить фильтры и поиск
Реализовать статистику и аналитику
Этап 7: Тестирование

Протестировать с реальными заказами
Обработать edge cases
Развернуть систему
