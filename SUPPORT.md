# Support

## Getting Help

Before opening a request:
1. Read `README.md`.
2. Check `docs/DOCUMENTATION_INDEX.md`.
3. Reproduce with latest `main`.

## Where to Ask

- Bug reports: GitHub Issues.
- Feature requests: GitHub Issues (label as enhancement).
- Security topics: see `SECURITY.md` (private reporting).

## What to Include

- environment (`OS`, Docker version, branch/commit);
- exact command and output;
- expected vs actual behavior;
- minimal reproducible example.

## Scope Note

This repository is an MVP and portfolio project.
Some production-grade topics are documented as roadmap items, not implemented by default.
