# Portfolio Overview

OrderFlow AI - учебный, но практически ориентированный e-commerce проект с акцентом на:
- омниканальный intake (`Telegram`, `web`, `email`);
- AI-извлечение структуры заказа из свободного текста;
- управляемый жизненный цикл заказа (state machine);
- интеграции с CRM, оплатой и доставкой;
- воспроизводимую демонстрацию и проверяемые артефакты качества.
